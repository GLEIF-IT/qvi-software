# KLI in Docker vLEI Workflow

This vlei-workflow.sh uses Docker containers for all KLI (KERIpy) setup of the GARs, QARs, LARs, and the Person.
The story covers credential issuance and admission through the Person; reporting endpoint deployment and presentation are outside this workflow.

## Usage

```bash
cd qvi-workflow/kli_docker
./vlei-workflow.sh
```

## Requirements

- Docker installed and running
- Docker Compose
